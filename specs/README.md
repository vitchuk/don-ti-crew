# Спецификации

Каждая фича — папка `NNN-name/` с тремя файлами:

- **spec.md** — цель, сценарии, требования (FR/NFR), вне объёма, критерии приёмки.
- **plan.md** — технический план: компоненты, контракты, данные, тест-план.
- **tasks.md** — малые задачи для subagents с критериями готовности и зависимостями.
