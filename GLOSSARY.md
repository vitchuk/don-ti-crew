# Глоссарий

Проект объединяет продукт — приложение для совместных тренировок родителя и ребёнка — и его собственную AI-инфраструктуру (Помощник по проекту, MCP, автоматический code review). Термины сгруппированы по областям.

## Тренировки

**Совместная тренировка**:
Тренировка родителя и ребёнка, которые занимаются рядом, перед одним экраном одного устройства.
_Avoid_: мультиплеер, синхронная тренировка (это про будущие возможности)

**Протокол Табаты**:
Параметры интервальной тренировки: длительность подготовки, работы, отдыха, число раундов в цикле, число циклов и отдых между циклами.
_Avoid_: настройки таймера, конфигурация

**Раунд**:
Один проход «работа → отдых» внутри цикла.

**Цикл**:
Группа раундов, завершающаяся отдыхом между циклами.

**Фаза**:
Текущий этап сессии: подготовка, работа, отдых, отдых между циклами или завершение.
_Avoid_: стадия, состояние таймера

**Пресет**:
Предустановленный шаблон тренировки, поставляемый вместе с приложением (например, «Табата 20/10 × 8 раундов»).
_Avoid_: стандартная тренировка, дефолт

**Шаблон тренировки**:
Именованный сохранённый протокол; применяется как пресет или создан пользователем.
_Avoid_: программа, тренировка

**Сессия**:
Один запуск шаблона от старта до завершения или прерывания, со сохранённым результатом.
_Avoid_: тренировка (перегруженный термин), подход

## Помощник по проекту

**Помощник (/help)**:
Web-интерфейс самого проекта, отвечающий на вопросы о проекте на основе документации, кода и проектного контекста.
_Avoid_: чат-бот, ассистент OpenCode

**Проектный контекст**:
Агрегированные сведения о репозитории — текущая ветка, состояние git, изменённые файлы — предназначенные для AI-потребителей.
_Avoid_: контекст модели, промпт

**Фрагмент знаний**:
Минимальный индексируемый кусочек документации или кода с указанием файла и заголовка, из которого он извлечён.
_Avoid_: чанк (допустимо в коде)

**Индекс знаний**:
Хранилище фрагментов знаний с эмбеддингами, по которому выполняется поиск.
_Avoid_: RAG-база

**Индексация**:
Построение и инкрементальное обновление индекса знаний по репозиторию.

**Цитата**:
Указание в ответе Помощника файла и заголовка, из которых взят использованный фрагмент.
_Avoid_: источник (допустимо неформально)

## AI-инфраструктура

**MCP-инструмент**:
Операция MCP-сервера, доступная AI-потребителям: часть проектного контекста или поиск по индексу знаний.
_Avoid_: команда, tool-вызов (допустимо в коде)

**AI-потребитель**:
Клиент MCP-сервера: OpenCode, Помощник по проекту или автоматический AI Code Review.
_Avoid_: пользователь (человек)

**AI Code Review**:
Автоматическое ревью pull request, публикуемое ботом одним обновляемым комментарием.

**Находка**:
Единичное замечание ревью: уровень серьёзности, файл, при необходимости строка, описание и рекомендация.
_Avoid_: issue, баг-репорт

**Self-hosted runner**:
GitHub Actions runner, установленный на локальной машине разработчика, где доступны локальные модели эмбеддингов.
_Avoid_: локальный агент
