# 0006 — Эмбеддинги и ревью выполняются на self-hosted runner

Локальная модель эмбеддингов (Ollama) недоступна облачным раннерам GitHub Actions, поэтому переиндексация и RAG-подготовка контекста для ревью выполняются на self-hosted runner, установленном на машине разработчика. Защита от выключенной машины: job, ожидающий офлайн-раннер, остаётся в очереди (GitHub не отменяет его автоматически) — используются ручная отмена и таймауты после старта (`timeout-minutes`: переиндексация ~10 мин, ревью ~15 мин); ревью в merge не блокирует. Ручной fallback — команда `pnpm rag:index`.
