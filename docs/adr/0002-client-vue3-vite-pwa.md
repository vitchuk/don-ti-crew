# 0002 — Клиент: Vue 3 + Vite PWA без нативных обёрток в MVP

Целевые платформы: браузер на ПК, Android, iOS. В MVP это одна кодовая база — Vue 3 + Vite + TypeScript + vite-plugin-pwa; обе мобильные платформы используют PWA-установку («на главный экран»). Capacitor-обёртки и публикация в магазинах отложены: нет Apple Developer-аккаунта, а Tabata-таймеру не требуется нативный функционал. Web-платформа первична — она явно указана первой в требованиях и является целью деплоя (GitHub Pages).
