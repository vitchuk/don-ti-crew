# 0007 — AI Code Review: non-blocking PR-комментарий

Ревью публикуется на каждое изменение PR одним комментарием от имени бота, который обновляется при новых push (без спама от дублирующихся сообщений). Находки ранжируются по четырём уровням: Critical, High, Medium, Low. Pipeline не блокирует merge: автомат — консультант, окончательное решение за человеком; блокировку можно включить позже без изменения архитектуры.
