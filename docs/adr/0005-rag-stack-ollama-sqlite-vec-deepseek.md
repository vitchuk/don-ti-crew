# 0005 — RAG-стек: Ollama qwen3-embedding + sqlite-vec + DeepSeek

Эмбеддинги всех фрагментов знаний считаются локально моделью qwen3-embedding через Ollama — приватно и без расхода токенов. Векторное хранилище — sqlite-vec: файловая БД без отдельного сервера, достаточно для индекса одного репозитория. Генерация ответов (Помощник и AI Code Review) — через DeepSeek API (ключ есть, качество выше локального qwen3:1.7b); локальная модель остаётся офлайн-фолбэком.

## Considered Options

- Qdrant/векторный сервис — отдельный сервис ради индекса одного репозитория; отклонено.
- Эмбеддинги через API — расход токенов на регулярную переиндексацию; отклонено.
- qwen3:1.7b как основной LLM слишком мал для качественного ревью кода; оставлен как фолбэк.
