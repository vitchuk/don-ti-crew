# 0001 — Монорепозиторий на pnpm с единым TypeScript

Продукт (Fitness-PWA) и AI-инфраструктура проекта (MCP, RAG-индексация, review, Помощник) живут в одном репозитории: RAG обязан индексировать README, документацию и исходный код самого проекта, а `/help` — функционал этого же проекта, поэтому раздельные репозитории усложнили бы и то, и другое. Менеджер пакетов — pnpm (workspace), язык — TypeScript во всех пакетах `apps/*` и `services/*`.

## Considered Options

- Отдельные репозитории для продукта и AI-инфраструктуры — изоморфная логика и индексация расползлись бы по копиям; отклонено.
- Python для RAG-части — второй тулчейн (env, линтеры, CI) ради нулевой пользы; отклонено.
